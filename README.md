Pharmacovigilance Case Study – Case 01

Project Overview

This project demonstrates my practical learning in Pharmacovigilance through a practice case. I independently practiced case intake, data extraction, adverse event narrative writing, and MedDRA coding.

Project Objectives

- Practice collecting and organizing safety information.
- Understand the basic pharmacovigilance case-processing workflow.
- Practice adverse event narrative writing.
- Understand MedDRA terminology and coding.

Project Files

1. Source Case: Source information used for practice.
2. Case Intake Form: Structured case information documentation.
3. Data Extraction: Organized extraction of relevant case details using Excel.
4. Case Narrative: Practice narrative writing based on the available case information.
5. MedDRA Coding: Practice coding the reported adverse event.

Skills Practiced

- Pharmacovigilance documentation
- Case intake and data extraction
- Adverse event narrative writing
- MedDRA coding practice
- Excel-based data organization
- Attention to detail

Learning Outcomes

This project helped me understand the basic workflow of a pharmacovigilance case and improve my documentation, data organization, and medical terminology skills.

Disclaimer

This is an educational practice project and does not represent professional industry experience or validated safety assessment.
